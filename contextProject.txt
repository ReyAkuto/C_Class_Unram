HERO:

- 6 keyframes: heroEyebrow, heroTitleReveal, heroSubtitle, heroActions, heroStats, heroPagination
- Hero shimmer: ::after diagonal sweep pada .hero-title
- PENTING: hero-loaded WAJIB di-trigger SEBELUM intro overlay split — bukan setelahnya
  (kalau dibalik → kedip/flicker saat transisi)

INTRO SCREEN (#introScreen):
- Full-screen overlay, direct child of <body>, z-index 9999
- Dua panel split: .intro-panel-left + .intro-panel-right
- Sequence: loading dots → "Wanna see our class?" + tombol → fade "Welcome" → panel split kiri-kanan
- hero-loaded di-fire SEBELUM screen.classList.add("exit")
- screen.remove() dipanggil 950ms setelah exit (setelah animasi selesai)
- Background music: window._bgMusic = new Audio('content/music/music.mp3')
  → WAJIB pakai window._bgMusic (bukan HTML element) agar tidak ikut ke-remove() bersama DOM
  → startMusic() dipanggil saat tombol "Let's go" diklik: seekTo second 17, loop manual via 'ended' event

PEOPLE DIRECTORY (#people):
- 39 avatar circle (72px, Instrument Serif italic), grid auto-fill minmax(80px)
- Marquee ticker: scrolling nama+track, velocity-based, triple-duplicate loop
- Filter pills: 8 track filters, dimmed class untuk non-match
- Floating member card: position fixed, direct child of <body> — BUKAN di dalam section
- Card positioning: positionCardByAvatar(idx) pakai getBoundingClientRect()
  → flip kiri/kanan otomatis, clamp y min 64px (navbar), clamp bottom viewport
  → Mobile (≤768px): card jadi bottom sheet, CSS override position (isMobile() check di JS)
- Tutup card: removeEventListener + 200ms delay sebelum attach baru (fix bug re-open)
- Cursor glow: blob biru, lerp 0.28, aktif hanya di #people, z-index 0

WORKS/PORTFOLIO (#works):
- Masih semester 1 → konten placeholder (ghost cards + semester progress bar)
- Comet canvas (#cometCanvas): absolute background, z-index 0
  → MAX_COMETS 7, SPAWN_RATE 0.018, sudut 35° miring kanan
  → Trail gradient + radial head glow, warna biru putih dingin
  → Seed 4 komet saat load dengan stagger 300ms
  → Semua child #works pakai z-index: 2 agar di atas canvas

ORG CHART + GALLERY (#org):
- Layout two-col (grid), jadi satu kolom di mobile
- Plexus canvas (#plexusCanvas): particle network background, absolute, z-index 0
  → 48 partikel, speed 0.35, connect distance 130px
  → Warna putih (255,255,255), line opacity max 0.12
  → Titik: spotlight kecil — bright core (radius 0.5x) + radial glow (radius 3x), opacity 0.7
  → Bounce di edges
- Gallery: renderGallery() inject foto dari content/moments/m1–m4.jpeg
  → onerror → item.style.display = 'none' (auto-hide kalau file tidak ada)
  → Layout grid: g-tall (kiri tall), g-sm (kanan atas), g-sm (kanan tengah), g-wide (bawah full)
  → Hover 300ms delay → item.classList.add('expanded') → scale(1.18), z-index 10
  → Siblings di-dim opacity 0.45 via :has() selector
  → Click → lightbox (#galleryLightbox): backdrop blur, scale from 0.93, close via backdrop/✕/Escape

FOOTER:
- Simple, center-aligned di mobile
